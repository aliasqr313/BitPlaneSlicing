# BitPlaneSlicing
پیاده‌سازی الگوریتم استخراج صفحات بیتی تصویر و بازسازی آن با پایتون و کتابخانه‌های OpenCV و NumPy.


# پروژه استخراج صفحات بیتی تصویر (Bit Plane Slicing)

## معرفی پروژه
این پروژه با استفاده از زبان برنامه‌نویسی پایتون و کتابخانه‌های پردازش تصویر، تکنیک استخراج صفحات بیتی (Bit Plane Slicing) را پیاده‌سازی می‌کند.

در این پروژه یک تصویر دریافت شده و به ۸ صفحه بیتی مجزا تقسیم می‌شود. سپس هر صفحه بیتی به‌صورت یک تصویر باینری نمایش داده می‌شود. در ادامه، هر بار یکی از صفحات بیتی حذف شده و تصویر با استفاده از ۷ صفحه باقی‌مانده بازسازی می‌شود.

## امکانات پروژه
- دریافت و نمایش تصویر اصلی به‌صورت خاکستری
- استخراج ۸ صفحه بیتی تصویر
- نمایش جداگانه صفحات بیتی از بیت صفر تا بیت هفت
- حذف هر یک از صفحات بیتی به‌صورت جداگانه
- بازسازی تصویر با استفاده از صفحات بیتی باقی‌مانده
- نمایش و مقایسه تصاویر بازسازی‌شده

## ابزارها و کتابخانه‌های استفاده‌شده

- OpenCV

- Matplotlib

## نحوه اجرای پروژه

۱. مخزن پروژه را دانلود یا Clone کنید.

۴. برنامه را با دستور زیر اجرا کنید:

```bash

```

## مراحل انجام پردازش

### ۱. دریافت تصویر
تصویر ورودی خوانده شده و به تصویر خاکستری تبدیل می‌شود.

### ۲. استخراج صفحات بیتی
با استفاده از عملیات شیفت بیتی و AND، هشت صفحه بیتی تصویر استخراج می‌شوند.

### ۳. نمایش صفحات بیتی
هر صفحه بیتی به‌صورت یک تصویر باینری شامل پیکسل‌های سیاه و سفید نمایش داده می‌شود.

### ۴. بازسازی تصویر
در هر مرحله یکی از صفحات بیتی حذف شده و تصویر با ترکیب هفت صفحه دیگر بازسازی می‌شود.

## نتیجه‌گیری

صفحات بیتی مختلف، اطلاعات متفاوتی از تصویر را در خود نگهداری می‌کنند. صفحات بیتی باارزش‌تر معمولاً نقش بیشتری در ساختار کلی و روشنایی تصویر دارند، درحالی‌که صفحات بیتی کم‌ارزش‌تر بیشتر در جزئیات ظریف و تغییرات کوچک روشنایی تأثیرگذار هستند.

با حذف صفحات بیتی می‌توان میزان تأثیر هر بیت بر کیفیت و ظاهر تصویر را بررسی کرد.
